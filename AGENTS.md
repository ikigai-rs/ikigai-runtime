# AGENTS.md

`ikigai-runtime` is a capability-gated WebAssembly host for ikigai: core modules and components
run with no authority but what a grant gives them.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text.
- Security reports go through [private vulnerability
  reporting](https://github.com/ikigai-rs/ikigai-runtime/security/advisories/new), never a public
  issue.
- Use American spelling (behavior, color, labeled, artifact).
